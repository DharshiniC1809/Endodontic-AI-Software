# Endodontic AI Prediction System

## Overview

The Endodontic AI Prediction System is a full-stack AI-powered dental application developed to assist dentists in predicting the success probability of endodontic treatments using dental imaging data.

The system supports both X-Ray and CBCT scan analysis and provides intelligent predictions through machine learning techniques integrated with image processing methods.

## Features

* User Authentication
* Forgot Password with Email OTP Verification
* X-Ray Scan Upload
* CBCT Scan Upload
* ROI (Region of Interest) Selection
* AI-Based Analysis
* Treatment Success Prediction
* Case History Management
* Report Generation
* PDF Report Download
* Profile Management
